# 阿瓦隆练习场 🗡️

一个人也能玩的《阿瓦隆》：你坐在桌边，其余座位全部由 **DeepSeek** 扮演的 AI 玩家填满。
每个 AI 都有自己的昵称和性格，会发言、带节奏、伪装、撒谎、刺杀梅林；
对局中可以随时叫 **教练** 给建议，结束后还能看所有 AI 的 **内心独白** 和 **AI 复盘**。

目标就两个：**玩得开心**，以及 **把阿瓦隆水平练上去**。

## 快速开始

只需要 Python 3.9+，**不需要安装任何依赖**。

```bash
git clone <这个仓库>
cd awalong

# 配置 DeepSeek API Key（也可以跳过这步，直接在网页里填）
cp .env.example .env
#   然后编辑 .env，填入 DEEPSEEK_API_KEY=sk-...

python run.py
```

启动后会自动打开浏览器：<http://127.0.0.1:8765/>

> DeepSeek API Key 在 <https://platform.deepseek.com/api_keys> 申请。
> 没有 Key 也能玩：开局时选择“离线规则 AI”（免费，但 AI 比较笨）。

## 功能

| | |
|---|---|
| 🎲 **标准规则** | 5~10 人局，标准角色配置、任务人数、第4轮双失败、5次否决、刺杀梅林；可选 **湖中仙女** |
| 🤖 **DeepSeek AI 玩家** | 每个 AI 只知道自己身份能看到的信息，有独立性格（老炮、新手、火爆、多疑、话痨……），记得自己之前的想法，保持前后一致 |
| 🎭 **自选角色和座位** | 想练梅林就指定梅林，想练刺客就指定刺客 |
| 💡 **教练提示** | 对局中随时点“教练”，它只用 **你能看到的信息** 分析局势、推测身份、给出行动建议 |
| 🏷️ **身份标记** | 点击座位下方的“标记”记下你对每个人的判断（好人 / 坏人 / 梅林?），结算时告诉你猜对几个 |
| 💭 **内心独白** | 对局结束后公开每个 AI 每一次发言、投票、出牌时的真实想法——对照一下你当时的判断 |
| 🧑‍🏫 **AI 复盘** | 上帝视角点评你的关键决策：哪里做得好，哪里可以更好，下一局练什么 |
| 📊 **数据统计** | 投票正确率、赞成过几次脏车、提名含坏人的次数等 |
| 👁 **观战模式** | 座位选“观战”，看一整局 AI 对局，身份全开、内心独白实时显示，学习梅林怎么藏、刺客怎么找 |
| 📱 **手机可玩** | 页面适配手机；设置 `AVALON_HOST=0.0.0.0` 后可用手机在局域网访问 |
| 💾 **对局存档** | 每局结束自动保存到 `records/` 目录（JSON，含全部信息） |

## 怎么用它提高水平

1. **专项练角色**：开局指定角色。新手建议先练 **忠臣**（纯推理）→ **派西维尔**（分辨梅林/莫甘娜）→ **梅林**（知道答案但要藏住）→ **刺客**（读出梅林）。
2. **先判断、再看答案**：每轮先自己在座位上打标记，想清楚了再点“教练”，比较你们的结论差在哪里。
3. **赛后看内心独白**：勾选“显示 AI 内心独白”，重读整局——你怀疑的人当时在想什么？你信任的人是怎么骗你的？
4. **看 AI 复盘**：重点看“可以改进的地方”，下一局只盯一两个点练。
5. **观战学套路**：看 AI 坏人怎么配合出牌、AI 梅林怎么用票型暗示好人。

## 一局的流程

1. 队长提名队伍（你当队长时，在圆桌上点选队员）。
2. 从队长下一位开始按座位顺序发言，你可以打字、用快捷短语，或者“过”。
3. 所有人同时投票，赞成票 **超过半数** 才发车；同一轮连续 5 次否决，坏人直接获胜。
4. 队员秘密出牌，好人只能出成功。
5. 先赢 3 轮的阵营获胜；好人赢了的话，坏人亮明身份讨论，刺客刺杀梅林翻盘。

## 关于速度和费用

- AI 是一个一个发言的，每次调用 DeepSeek 需要几秒。7 人局一轮讨论大约半分钟，觉得慢可以把“AI 发言长度”调成“简短”。
- 一局大约调用几十到一百多次 API。提示词做了前缀缓存优化（对局记录放在最前面，只追加不修改），大部分输入能命中 DeepSeek 的缓存。
  页面右上角会实时显示调用次数和 token 用量，以 DeepSeek 目前的价格一局通常花不到 1 元（具体以官网价格为准）。
- DeepSeek 调用失败（网络问题、Key 错误、余额不足）时，AI 会自动改用离线策略继续游戏，对局记录里会有提示。

## 配置

可以写在 `.env` 文件里，也可以作为环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | （空） | DeepSeek API Key；为空时可以在网页里填写 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 模型名；`deepseek-reasoner` 会更慢 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 也可以换成其他 OpenAI 兼容接口 |
| `AVALON_HOST` | `127.0.0.1` | 改成 `0.0.0.0` 可以让局域网里的手机访问 |
| `AVALON_PORT` | `8765` | 端口 |
| `AVALON_OFFLINE_PACE` | `0.9` | 离线 AI 每句话之间停顿的秒数 |

命令行参数：`python run.py --port 9000 --no-browser`

## 项目结构

```
run.py              启动入口
avalon/
  rules.py          规则常量：角色、人数配置、视野
  engine.py         对局引擎（后台线程推进游戏，等待人类输入）
  brains.py         人类玩家接口 + 离线规则 AI
  llm.py            DeepSeek 驱动的 AI 玩家
  prompts.py        提示词：规则、身份、策略、对局记录渲染
  deepseek.py       极简 DeepSeek（OpenAI 兼容）客户端
  coach.py          教练提示、赛后复盘、数据统计
  personas.py       AI 玩家的昵称和性格
  server.py         本地 HTTP 服务和 API
static/             网页（原生 HTML/CSS/JS，无构建步骤）
tests/              单元测试（含一个假的 DeepSeek 服务）
```

## 测试

```bash
python -m unittest discover -s tests -v
```
